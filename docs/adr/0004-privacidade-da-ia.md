# ADR 0004 — Consentimento para IA futura

**Status:** Aceita como diretriz de produto · 2026-11-19

## Decisão

Organização por IA é opcional e não necessária para ações básicas. O app deve exibir uma prévia de sugestões estruturadas, editáveis pelo usuário, sem gravação automática. Qualquer envio remoto exige opt-in e clareza sobre provedor, retenção e custo.

## Consequência

Nenhum SDK de IA/API key/modelo ou telemetria incluídos no MVP. Introduzir a feature requer nova spec de dados, consentimento, validação e testes de prompt injection/saída ambígua.
